Параметры сварки (номера режимов и настройки оборудования) для всех точек точечной сварки на данном автомобиле, включая
детали из высокопрочной стали (1500 МПа), приведены в Главе 3 «Замена деталей», разделы «Установка». Выполняйте сварку в
строгом соответствии с указанными параметрами.

!!! tip "Рекомендация"

    - Перед работой с точечной сваркой, не затрагивающей детали из высокопрочной стали (1500 МПа), ознакомьтесь с Главой 1 «Информация по
    техническому обслуживанию» [Спецификация деталей кузова](000000000000012.md), чтобы определить толщину листа, предел
    прочности на растяжение и наличие цинкового покрытия с обеих сторон, а затем настройте сварочное оборудование в
    соответствии с этими данными.
    - Сверьтесь с технической документацией производителя сварочного аппарата.
