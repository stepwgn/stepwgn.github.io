Места пайки MIG для деталей из высокопрочной стали (1500 МПа) на данном автомобиле указаны в разделах «Установка» Главы
3 «Замена деталей». Для обеспечения надежного соединения соблюдайте следующие условия.

!!! info "Справочная информация"

    Температура в зоне соединения при сварке MAG достигает примерно **1500 °C**, что может привести к значительному
    ухудшению механических свойств высокопрочных стальных листов. Температура при пайке MIG составляет около **950 °C**,
    поэтому для данных сталей предпочтительным методом является именно пайка MIG.

!!! tip "Рекомендация"

    **Запрещается** выполнять сварку MAG деталей из высокопрочных стальных листов (1500 МПа).

## Условия пайки MIG

- Сварочный аппарат: используйте аппарат с импульсным управлением.
- Сварочная проволока: CuSi3
- Защитный газ: Ar 100%

### Соединение силовых (конструктивных) элементов

!!! tip "Рекомендация"

    Во избежание снижения прочности соединения, **запрещается** шлифовать или удалять наплавленный припой.

При соединении детали из высокопрочной стали (≥340 МПа) с деталью из высокопрочной стали (1500 МПа) выполняется
соединение силовых элементов. Для этого просверлите два отверстия диаметром 8,0 мм с расстоянием между центрами
приблизительно 10 мм.

### Соединение наружных панелей (обшивки)

!!! tip "Рекомендация"

    Наплавленный припой подлежит последующей шлифовке для финишной обработки поверхности.

При соединении детали из низкоуглеродистой стали (270 МПа), такой как наружная панель, с деталью из высокопрочной
стали (1500 МПа), перед пайкой просверлите одно отверстие диаметром 8,0 мм (φ8,0 мм) в детали из стали 270 МПа.

## Методика пайки MIG

Принцип соединения: Расплавленный присадочный материал должен обладать достаточной текучестью, чтобы проникнуть в зазор
между верхним и нижним листами под действием капиллярного эффекта.

Техника выполнения: Используя функцию импульса сварочного аппарата, начните процесс пайки примерно за 5,0 мм до края
отверстия и завершите его примерно через 10 мм после выхода из отверстия.
