<a id="i01601"></a>
<div class="servinfosub_title">Ремонтная краска</div>
<a id="i02901"></a>
<br/>
<div class="topic_title">Ретушь новых автомобилей (включая гарантийный ремонт), аварийные автомобили и перекраска</div>
<br/>
<div>Для сохранения качества, сопоставимого с качеством краски, используемой на серийных автомобилях, используются однокомпонентные, двухкомпонентные краски на основе акрило-уретановой смолы или краски на водной основе.</div>
<a id="i03616"></a>
<div>
<img src="../img/new-attention_jpn_226723_1.0.png"/>
<div>Не производите ремонт с использованием красок на основе акриловых лаковых смол.</div>
</div>
<div>Методы ремонта см. в Руководстве по техническому обслуживанию, Основы технического обслуживания и покраски кузова, 60PRM30.</div>
