## Лакокрасочные материалы для ремонта

### Ремонт новых автомобилей (включая гарантийный), восстановление после повреждений и полная перекраска

Для обеспечения качества, сопоставимого с конвейерным покрытием, применяются однокомпонентные, двухкомпонентные
акрило-уретановые краски или краски на водной основе.

!!! tip "Рекомендация"

    Не производите ремонт с использованием красок на основе акриловых лаковых смол.

Методы ремонта см. в Руководстве по техническому обслуживанию, Основы технического обслуживания и покраски кузова,
60PRM30.
